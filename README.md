# Python Practice — Day 1 & 2

A collection of beginner Python scripts covering core language fundamentals.

## Files

| File | Topics covered |
|------|---------------|
| `hello.py` | Hello World |
| `data-types.py` | Strings, integers, floats, booleans, lists, dicts, tuples |
| `demo.py` | Functions, user input, variable swapping, `math` module |
| `if_demo.py` | `if / elif / else`, `match / case` |
| `while_demo.py` | `while` loops, nested loops |
| `for_demo.py` | `for` loops, `range()`, `break` / `continue` |
| `array_demo.py` | `array` module — typed arrays, iteration, reverse, copy |
| `func_arg.py` | Default args, `*args` (variable-length), `**kwargs` (keyword args) |

## Running a script

```bash
python <filename>.py
```

Requires Python 3.10+ (uses `match / case` syntax).
